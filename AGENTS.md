# Winnet Construction Ltd — Web Application & Architecture Guide

## Project Overview
This repository powers the official web application and client portal for **Winnet Construction Ltd** (Ghana).
The application is built with:
- **TanStack React Start & TanStack Router**: Full SSR & SPA routing with type-safe route trees.
- **Tailwind CSS v4 & Lucide Icons**: Premium construction-themed UI design (deep ink canvas, warm gold accents `#F2B23C`, architectural typography).
- **Schema.org & Google SEO Optimization**: Structured data (`GeneralContractor`, `WebSite`, `BreadcrumbList`), dynamic meta tags, automated sitemap, and multi-platform PWA icons.

## Development & Build Commands
- `npm run dev`: Starts the local development server.
- `npm run build`: Compiles production assets and route trees.
- `npm run lint`: Runs ESLint validation.
